# MyPinkShop Backend (Hono + D1 + R2)

## Features
- User Auth (JWT + Refresh Token)
- Product CRUD + Search + Filters + Pagination
- R2 Image Upload
- Orders + Nykaa-style Order ID
- Order Status + Payment Webhook
- Address CRUD
- Reviews & Ratings
- Wishlist
- Cart
- Admin APIs (User Management)
- Vendor APIs (Product Management)
- Dashboard Stats

## Deploy Steps
1. Create D1 database
2. Create R2 bucket
3. Update wrangler.toml with IDs
4. Deploy to Cloudflare Pages
